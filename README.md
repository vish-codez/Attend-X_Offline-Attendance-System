# Attend-X: Offline Attendance System

A robust, full-stack attendance management solution designed with offline support to seamlessly track student records without relying on constant internet connectivity. 

## 👥 Team & Contributions
* **Vishwaa U (Lead Backend & Database Developer):** Architected the core REST APIs, structured the relational database schemas, and implemented backend application logic.
* **Collaborator:** Managed frontend module integrations.

## 🚀 Key Features
* **Offline Synchronization:** Locally caches attendance data and syncs automatically when a connection is established.
* **Secure REST APIs:** Power-packed endpoints handling user authentication, student lookups, and logs.
* **Relational Database Design:** Highly optimized schemas to handle frequent read/write transaction flows.

## 🛠️ Tech Stack
* **Backend:** Spring Boot (Java)
* **Frontend:** Flutter (Dart)
* **Database:** MySQL
* **Architecture:** RESTful Web Services
